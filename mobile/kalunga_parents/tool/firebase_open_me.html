Push app fermée — tes 3 clics seulement

Le reste est automatisé dans Cursor. Toi : connexion Google + création projet + téléchargement.

Package Android (à coller tel quel) :
net.institutkalunga.parents

1. Ouvrir Firebase Console 2. Paramètres projet 3. Cloud Messaging (clé)

Étapes (2–5 minutes)
  1. Connecte-toi avec ton compte Google de l’école.
  2. Crée un projet nommé Institut Kalunga (Google Analytics : tu peux désactiver).
  3. Ajoute une app Android → package : net.institutkalunga.parents → Enregistrer.
  4. Télécharge google-services.json (dossier Téléchargements).
  5. Cursor le détecte et le copie tout seul dans l’app.
  6. Dans Paramètres du projet → Cloud Messaging, copie la Clé serveur (Server key) et colle-la dans le chat Cursor.
Important : sans ce fichier Firebase, Android ne peut pas recevoir de notif si l’app est fermée (même règle que WhatsApp : ça passe par Google).
